
# 🛰️ SatQuery AI
### Ask Your Satellite Images Anything

SatQuery AI is an AI-powered Interactive Vision-Language Assistant designed to help users understand and analyze satellite imagery using natural language.

Instead of manually interpreting complex satellite images, users can interact with the system by asking questions and receiving AI-generated insights.

## 🌍 Project Overview

SatQuery AI combines Artificial Intelligence, Computer Vision, Deep Learning and Earth Observation technologies to make satellite image analysis more accessible.

## ✨ Key Features

- Satellite Image Understanding
- Natural Language Question Answering
- AI-powered Image Analysis
- Earth Observation Model Integration
- Interactive User Interface
- Intelligent AI-assisted Insights

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd SATQUERY-AI
```

### 2. Backend Setup

Create a Python virtual environment:

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the backend:

```bash
python -m backend.server
```

### 3. Frontend Setup

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

### 4. Environment Configuration

Create a local `.env` file and configure the required API credentials.

Never upload API keys, passwords or secret credentials to GitHub.
